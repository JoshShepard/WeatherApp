# 🌦️ Weather Dashboard App

A responsive, user-friendly weather application built with **vanilla JavaScript**, **HTML**, and **CSS**. This project fetches real-time weather data using the [WeatherAPI](https://www.weatherapi.com/) and displays it in a visually engaging dashboard.

---

### 📌 Features

- 🔍 **Search by city** to get the current weather conditions
- 🌡️ **Temperature display** 
- 💨 **Wind speed display** 
- 💧 **Humidity readings**
- 🖼️ **Dynamic weather icons** based on condition codes
- 📱 **Fully responsive design** (mobile/tablet/desktop)
- 🎨 **Clean, modern UI with animations** (in progress)

---

### 🧰 Tech Stack

| Tech         | Purpose                      |
|--------------|------------------------------|
| HTML5        | Markup / structure            |
| CSS3         | Styling, Flexbox, Media Queries |
| JavaScript   | DOM manipulation, API calls   |
| WeatherAPI   | Fetching live weather data    |
| Font Awesome | Icons                         |
